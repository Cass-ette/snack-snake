# 粉蓝蛇蛇 · Snack Snake

给粉蓝小蛇戴上圆框眼镜，塞点 M 豆、黑巧和汉堡，再让炫神进来砍两刀。核心还是贪吃蛇，只是零食和干扰都多了一点。电脑、手机都能玩，打开网页就能开吃。

**现在开玩：** [IP 入口（80 端口）](http://8.147.59.78:80/snacksnake/)。域名 [viper3.icu](http://viper3.icu/) 还在等备案，等我搞定了，也能直接从那边进。

**代码已经开源。** 想改点什么、加点新活，欢迎拿去折腾，也欢迎提建议。

## 怎么玩

- 电脑：方向键 / WASD 转向，空格暂停，E 开毒雾。
- 手机：在棋盘上滑一滑，或者点下方方向键；毒雾也有单独按钮。
- M 豆加浓度，80% 黑巧直接拉满；汉堡真香，但会掉 8%。满浓度的下一口 M 豆 / 汉堡双倍得分。
- 炫神会提前画出横竖线，然后“我砍，我再砍”。毒雾能挡斧头，墙和自己还是要躲。
- 探照果实会照出小蛇，队友还说“潘森没大”——接着小天真跳进来了。离开金色椭圆就能躲开，毒雾也能挡住；落地命中最多扣 20 分、3 节尾巴和 8% 浓度。
- 卡尔玛会来 W 你：**2 秒内跑出她的圆圈就能挣脱**，否则定身约 1.4 秒。她本人不挡路，毒雾不挡牵线；定身期间斧头照常出，方向可以提前按。出场有冷却，空窗越久越容易来；暂停会冻结计时。
- 经典撞墙、快乐穿墙两种模式。音效和原梗人声默认开，想安静吃也能关。
- 小蛇战袍随时换：**BLG 粉蓝、Griffin 红白、EDG 黑白、HLE 橙灰**。换色不清空本局，刷新也会记住选择。

粉蓝是 BLG 的那件；Griffin 是梦开始的地方，EDG 是 2021 年捧杯的那一站，HLE 也有两段经历。这次把几件战袍都带上了。页面也换成了深灰底、固定细颗粒和淡淡的字符光场，中文仍然用系统黑体。

## 这次更新的新活

卡尔玛牵线、探照果实和小天潘森已加入游戏。三路干扰采用带冷却的伪随机：未触发时逐次提高概率，触发后重新开始冷却，起手之间留一点间隔；牵线与跳大不会同时起手。

后面再找几个英雄来串门。有好玩的点子也可以提，先看看小蛇还能遭多少罪。

新增的卡尔玛，灵感来自 [Viper 开局下路阵亡片段](https://www.bilibili.com/video/BV1QGHA67EMM/)。视频是 BLG 对 MKOI 的开局下路交战；游戏取了卡尔玛 W 的牵线与定身机制。潘森部分参考 [探照果实后被开](https://www.bilibili.com/video/BV1k1xP6EEbE/) 和 [“潘森没大”的采访讨论](https://www.bilibili.com/video/BV1tsxe65ERN/)；R 被打断后返还冷却是相关讨论对报错原因的推测。

## 自己跑 / 自己改

直接打开仓库里的 `index.html` 就能玩。也可以启动一个静态服务：

```sh
python3 -m http.server 8765
```

改 `src/` 后运行 `python3 scripts/build.py`，会生成带内嵌原声的单页 `index.html`；不需要前端构建工具。现有逻辑测试：`node --test tests/*.test.cjs`。
